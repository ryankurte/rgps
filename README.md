# rgps(c|d)

A rust-based gps daemon with dynamic NTRIP support.

## Status

[![GitHub tag](https://img.shields.io/github/tag/ryankurte/rgps.svg)](https://github.com/ryankurte/rgps)
![Build Status](https://github.com/ryankurte/rgps/workflows/CI/badge.svg)

## Components

- [ctl] provides a command line interface for interacting with the daemon
- [daemon] provides the rgps daemon implementation
- [proto] defines the messages used to communicate with the daemon
